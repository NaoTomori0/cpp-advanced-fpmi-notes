# Конспекты лекций по C++: Продвинутый поток ФПМИ (2023-2024)

Личный репозиторий с конспектами, кодом и материалами по курсу **«Программирование на языке C++»** продвинутого потока ФПМИ МФТИ за 2023-2024 учебный год.

## 📌 О курсе

- **Лектор:** Илья Мещерин
- **Площадка:** ФПМИ МФТИ (1 курс)
- **Уровень:** Продвинутый (глубокое погружение в устройство языка, стандарты и управление памятью)

## 🗂 Структура репозитория

- `/lectures` — текстовые конспекты и основные тезисы лекций.
- `/code_examples` — примеры программ, разборы специфического поведения компилятора и стандартов.
- `/assignments` — (опционально) решения задач и лабораторных работ.

## 🚀 Ключевые темы курса

1. **Основы и низкоуровневое устройство:** модели памяти (стек, статика, динамика), указатели, ссылки, константная корректность.
2. **ООП и полиморфизм:** устройство классов, виртуальные функции (`vtable`), множественное наследование.
3. **Шаблоны (Templates):** метапрограммирование, SFINAE, концепты.
4. **Стандартная библиотека:** STL-контейнеры, итераторы, аллокаторы и умные указатели.
5. **Современные стандарты:** особенности C++11/14/17/20/23.
