# Конспекты лекций по C++: Продвинутый поток ФПМИ (2023-2024)

Личный репозиторий с конспектами, кодом и материалами по курсу **«Программирование на языке C++»** продвинутого потока ФПМИ МФТИ за 2023-2024 учебный год.

### ⚠️ Требования к уровню знаний

Курс **не предназначен для изучения языка с нуля**. Предполагается, что вы уже имеете базовый опыт программирования на C++ или C. В рамках лекций мы не тратим время на разбор элементарного синтаксиса (например, что такое `std::cout`, как устроены циклы `for` или базовые условные операторы). Вместо этого фокус сразу смещается на глубокое понимание стандартов, внутреннее устройство механизмов языка и компилятора.

💡 **Если вам нужно повторить базу:**
Рекомендуется сначала ознакомиться с [Базовым курсом C++ от Ильи Мещерина (C++ Лекции МФТИ Мещерин)](https://www.youtube.com/playlist?list=PLoNf82n__sV4_evodYxUhNIQIliCvGXyl), где последовательно объясняются самые основы программирования для начинающих.

## 📌 О курсе

- **Лектор:** Илья Мещерин
- **Площадка:** ФПМИ МФТИ (1 курс)
- **Уровень:** Продвинутый (глубокое погружение в устройство языка, стандарты и управление памятью)

## 🗂 Структура репозитория

- `/lectures` — текстовые конспекты и основные тезисы лекций.
- `/code_examples` — примеры программ, разборы специфического поведения компилятора и стандартов.
- `/assignments` — (опционально) решения задач и лабораторных работ.

📚 **Рекомендуемая литература для курса:**

- **Скотт Мейерс — «Эффективный современный C++»** (идеально для понимания стандартов C++11/14 и концепций вроде Move-семантики).
- **Бьёрн Страуструп — «Язык программирования C++»** (фундаментальный справочник от автора языка для уточнения деталей).
- **Энтони Уильямс — «Параллельное программирование на C++ в действии»** (потребуется во втором семестре при разборе многопоточности / Concurrency).
- **cppreference.com** — главный и самый актуальный онлайн-справочник, заменяющий любую бумажную книгу при проверке стандартов.

## 🚀 Ключевые темы курса

1. **Основы и низкоуровневое устройство:** модели памяти (стек, статика, динамика), указатели, ссылки, константная корректность.
2. **ООП и полиморфизм:** устройство классов, виртуальные функции (`vtable`), множественное наследование.
3. **Шаблоны (Templates):** метапрограммирование, SFINAE, концепты.
4. **Стандартная библиотека:** STL-контейнеры, итераторы, аллокаторы и умные указатели.
5. **Современные стандарты:** особенности C++11/14/17/20/23.
